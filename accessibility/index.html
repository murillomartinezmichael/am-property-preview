Accessibility

This public preview is designed to be usable with a keyboard, at narrow screen widths and with reduced motion preferences.

What is included

  • A skip link and semantic navigation.
  • Visible keyboard focus and labeled controls.
  • Descriptive alternative text and a visible AI concept disclosure.
  • Responsive layouts and no automatic animation.

Current limitations

This is not a certification of WCAG compliance. Screen-reader testing and owner review remain pending. A verified contact method for accessibility feedback has not been supplied yet.

The inquiry checklist works locally and does not submit or save information. A text fallback is available when JavaScript is disabled.
